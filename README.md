# 🤖 Торговый помощник

CLI-бот для анализа криптовалютных пар. Данные берутся с **Binance** (без API-ключей).

## Возможности

- **Полный анализ** — цена, объём, изменение за 24ч
- **Тренд** — на таймфреймах 1H, 4H, 1D (EMA, SMA, RSI, MACD)
- **Фибоначчи** — уровни 23.6%–78.6%, золотая зона, зоны входа для лонга/шорта
- **Рекомендация по входу** — ВХОДИТЬ / ЖДАТЬ / НЕ ВХОДИТЬ для лонга и шорта
- **Волатильность** — ATR, дневная σ, диапазон 24ч
- **Фандинг** — ставка + вердикт: входить в лонг/шорт или нет
- **Уровни** — поддержка и сопротивление
- **Сигналы** — автоматические подсказки
- **Моя позиция** — ввод входа, суммы, плеча, лонг/шорт → стоп, тейк, PnL в USDT и %

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

### С кнопками (веб-интерфейс) — рекомендуется

```bash
py web_app.py
```

Откроется браузер с кнопками для популярных пар (BTC, ETH, SOL и др.).

### Консоль

```bash
py bot.py
py bot.py ETH/USDT
```

## Примеры пар

- `ETH/USDT`
- `BTC/USDT`
- `SOL/USDT`
- `DOGE/USDT`

## ⚠️ Дисклеймер

Это инструмент для анализа, а не финансовая рекомендация. Торгуйте на свой риск.
