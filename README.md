# Торговый терминал

Веб-приложение и CLI для анализа **крипто**, **акций** и **форекс**. Данные: Binance (крипто) и Yahoo Finance (акции/валюта). API-ключи не нужны.

## Возможности

- Свечной график (всегда на экране) + funding для крипты
- TradingView по ссылке и в раскрывающемся блоке
- Тренд 1H / 4H / 1D, MACD, RSI, структура рынка, ADX
- Фибоначчи, зоны входа лонг/шорт
- Рекомендации: ВХОДИТЬ / ЖДАТЬ / НЕ ВХОДИТЬ
- Скальпинг 5m / 15m
- Менеджер рисков и калькулятор позиции
- **Точность анализа** — согласованность ТФ, простой бэктест 4H, класс A–D

## Быстрый старт

### Требования

- Python **3.10+** (рекомендуется 3.11)
- Windows: команда `py` или `python`

### Установка

```bash
# Распакуйте архив или клонируйте репозиторий
cd Trading

# Виртуальное окружение (рекомендуется)
py -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate  # Linux / macOS

pip install -r requirements.txt
```

### Запуск

```bash
py web_app.py
```

Откройте в браузере: **http://127.0.0.1:5000**

### Консоль (без веба)

```bash
py bot.py ETH/USDT
```

## Точность анализа

Показатель **не гарантирует прибыль**. Это оценка согласованности сигналов (таймфреймы, индикаторы, упрощённый бэктест на 4H). Класс **A** — высокая согласованность, **D** — лучше подождать.
