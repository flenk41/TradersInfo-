# Trading Info Stats (TIS)

[![CI](https://github.com/flenk41/TradersInfo-/actions/workflows/ci.yml/badge.svg)](https://github.com/flenk41/TradersInfo-/actions/workflows/ci.yml)

> Веб-терминал торговой аналитики. Проект под **двойной лицензией**:
> открытый по **AGPL-3.0** для сообщества и **платный по коммерческой лицензии**
> для закрытого/коммерческого использования (см. раздел [Лицензия](#лицензия)).
> Запуск: `py web_app.py`.

## Торговый терминал

Веб-приложение и CLI для анализа **крипто**, **акций** и **форекс**. Данные: Binance (крипто) и Yahoo Finance (акции/валюта). API-ключи не нужны.

## Возможности

- Свечной график (всегда на экране) + funding для крипты
- TradingView по ссылке и в раскрывающемся блоке
- Тренд 1H / 4H / 1D, MACD, RSI, структура рынка, ADX
- Фибоначчи, зоны входа лонг/шорт
- Рекомендации: ВХОДИТЬ / ЖДАТЬ / НЕ ВХОДИТЬ
- Скальпинг 5m / 15m
- Менеджер рисков с расчётом цены ликвидации (учёт комиссий)
- **Согласованность сигналов** — балл 0–100 (ТФ, индикаторы, простой бэктест 4H), класс A–D

## Быстрый старт

### Требования

- Python **3.10+** (рекомендуется 3.11)
- Windows: команда `py` или `python`

### Установка

```bash
# Распакуйте архив или клонируйте репозиторий
cd Trading

# Виртуальное окружение (рекомендуется)
py -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate  # Linux / macOS

pip install -r requirements.txt
```

### Запуск

```bash
py web_app.py
```

Откройте в браузере: **http://127.0.0.1:5000**

### Консоль (без веба)

```bash
py bot.py ETH/USDT
```

## Согласованность сигналов

Балл **не является вероятностью прибыли**. Это оценка согласованности сигналов (таймфреймы, индикаторы, упрощённый бэктест на 4H) по шкале 0–100. Класс **A** — высокая согласованность, **D** — лучше подождать.

## Тесты

```bash
pip install -r requirements.txt
py -m pytest -q
```

Покрыты `position_calculator` (стоп/тейк, ликвидация) и `risk_manager` (размер позиции, лимиты, R:R).

## Безопасность и эксплуатация

- **Это локальный инструмент.** По умолчанию сервер слушает `127.0.0.1`. На дорогих эндпоинтах включён per-IP rate-limit (отключается `RATE_LIMIT_OFF=1`). Перед публикацией в интернет добавьте авторизацию/обратный прокси.
- **Ключ OpenAI** хранится только в `.env` (в `.gitignore`). Если ключ где-то засветился — **отзовите и перевыпустите** его в панели OpenAI. В репозитории и `.env.example` реального ключа нет.
- На Windows для прод-режима используйте `waitress` вместо `gunicorn`.
