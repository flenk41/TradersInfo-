# 🤖 TIS Bybit bot — самостоятельный торговый бот

> ⚠️ Запускаешь **ты**, на **своей** машине, со **своими** ключами. Веб-приложение
> TIS бота **не запускает** и ключи **не хранит**. Торговля с плечом — высокий риск
> потери средств. Это **не финансовый совет**.

Бот торгует по стратегии TIS (тренд EMA20/50 + фильтр EMA200 + RSI, стоп по ATR,
тейк по R:R, размер от риска в %). По умолчанию — **бумажный режим на testnet**:
реальные ордера не отправляются.

## 1. Установка
```bash
pip install requests pandas numpy
```

## 2. Ключи (только через переменные окружения)
Создай на Bybit API-ключ с правами **Read + Trade**, **БЕЗ Withdraw** (вывод).
Лучше — суб-аккаунт с малым балансом и привязкой по IP.

```bash
export BYBIT_API_KEY="твой_ключ"
export BYBIT_API_SECRET="твой_секрет"
```
(Windows PowerShell: `$env:BYBIT_API_KEY="..."`)

## 3. Запуск — сначала БУМАЖНО
В файле `tis_bybit_bot.py` настройки вверху (SYMBOL, INTERVAL, RISK_PCT, …).
По умолчанию `MODE="paper"`, `TESTNET=True` — бот только печатает сигналы.

```bash
python bots/tis_bybit_bot.py
```
Посмотри день-два, совпадают ли сигналы с тем, что ждёшь.

## 4. Testnet с реальными (тестовыми) ордерами
Получи тестовые средства на testnet.bybit.com → оставь `TESTNET=True`,
поставь `MODE="live"`. Бот будет ставить ордера тестовыми деньгами (риска нет).

## 5. Mainnet (реальные деньги) — только осознанно
Тройная защита, чтобы случайно не уйти в бой:
1. `MODE="live"`
2. `TESTNET=False`
3. переменная окружения `TIS_BOT_CONFIRM_LIVE=YES`

Без всех трёх бот на mainnet **не отправит ни одного ордера**.

```bash
export TIS_BOT_CONFIRM_LIVE=YES
python bots/tis_bybit_bot.py
```

## Что бот делает и НЕ делает
- ✅ Читает публичные свечи, считает сигнал, ставит **рыночный ордер с
  прикреплённым стопом и тейком**; плечо подбирает так, чтобы стоп срабатывал
  раньше ликвидации (≤ `LEVERAGE_CAP`); размер — от `RISK_PCT`.
- ❌ Никогда не выводит средства, не трогает другие инструменты, не торгует
  без явного подтверждения live.

## Рекомендации
- Начни с **1 инструмента**, малого `RISK_PCT` (0.5–1%) и `LEVERAGE_CAP` 5–10.
- Сначала прогони стратегию в **«📊 Бэктест»** приложения — убедись, что PF > 1.3
  при ≥30 сделках на твоём инструменте/ТФ.
- Держи бота под присмотром; биржа/сеть могут сбоить.
