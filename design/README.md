# design/ — рабочая папка для UI-дизайна (Stitch)

> ⚠️ **Удаляемая папка.** Никакого продакшен-кода тут нет — только материалы для
> проектирования интерфейса. Можно удалить целиком без последствий для приложения.
>
> ⚠️ **Никаких ключей/токенов в этой папке и репозитории.** Токен Stitch — секрет
> вашей сессии; работайте с ним только в браузере на stitch.withgoogle.com.

## Зачем
[Google Stitch](https://stitch.withgoogle.com/) — интерактивный генератор UI (на Gemini).
Он работает **в браузере**, поэтому процесс такой:

1. Откройте Stitch, войдите своим аккаунтом.
2. Вставьте промпт из [`stitch-prompt.md`](stitch-prompt.md) (он описывает наш продукт
   и фирменный стиль — тёмная тема, индиго→фиолет, все вкладки и компоненты).
3. Сгенерируйте экраны, доведите руками.
4. **Export → HTML/CSS** (или Figma) → положите в `design/exports/<экран>/`.
5. Скажите мне — я адаптирую разметку/стили под наш стек (vanilla JS + CSS,
   переменные из `static/style.css` / `refresh-pro.css`) и аккуратно интегрирую.

## Что НЕ делаем
- Не вставляем сгенерированный HTML «как есть» в прод (у Stitch свои классы/инлайны) —
  адаптируем под наши компоненты и дизайн-токены.
- Не тащим внешние CDN/шрифты без необходимости (CSP в `web_app.py`).

## Текущий фирменный стиль (для согласованности)
- Фон `#0a0e17`, поверхности `#131a28`, акцент `#6d6dfb` → `#b45cff` (градиент).
- Радиус 16px, стекло (blur+saturate), мягкие тени, `Inter`, tabular-nums для цифр.
- Сигнальные цвета: рост `#34d399`, падение `#fb7185`, ожидание `#f59e0b`.
