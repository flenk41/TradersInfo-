# Промо-слайды для TikTok / Reels / Shorts

`index.html` — 6 готовых вертикальных кадров **1080×1920 (9:16)** в фирменном стиле TIS.

## Как экспортировать в картинки
1. Открой `index.html` в Chrome.
2. **Скриншот одного кадра:** DevTools (F12) → выбери элемент `<section class="slide">` → ПКМ → **Capture node screenshot**. Получишь PNG ровно 1080×1920.
3. **Все сразу:** DevTools → эмуляция устройства (Ctrl+Shift+M) → задай размер `1080 × 1920` → листай якорями `#s1 … #s6` и делай скриншоты.

## Как сделать видео
- Запиши экран, листая кадры (`#s1`→`#s6`), 1.5–2.5 c на кадр.
- Либо собери PNG-кадры в любом видеоредакторе/CapCut, добавь музыку и переходы.

## Сценарий (озвучка/подписи)
1. **Хук** — «Хватит гадать: терминал говорит, что делать».
2. **План сделки** — «Зелёный — заходи, жёлтый — жди, красный — пропусти».
3. **Smart Money** — «Видит зоны умных денег: ордер-блоки, ликвидность».
4. **Рисование + Live** — «Рисуй как в TradingView, график живой».
5. **Твои правила** — «Сигналы под твою стратегию».
6. **CTA** — «Бесплатно, без регистрации. Telegram @TradingInfoStats».

Тексты, цифры и цвета меняются прямо в `index.html`. Папка `marketing/` — вспомогательная, в продукт не входит.
