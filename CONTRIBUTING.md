# Контрибьютинг / Contributing

Спасибо за интерес к **Trading Info Stats**! Несколько важных моментов.

## Лицензия и передача прав (важно для dual licensing)

Проект распространяется по модели **двойного лицензирования**: открытая
**AGPL-3.0** + платная **коммерческая лицензия** (см. [COMMERCIAL.md](COMMERCIAL.md)).

Чтобы правообладатель мог **продолжать выдавать коммерческие лицензии**, он должен
оставаться единственным владельцем прав на весь код. Поэтому, отправляя
Pull Request, вы соглашаетесь, что:

1. Ваш вклад оригинален и вы вправе его передать.
2. Вы предоставляете правообладателю (flenk41 / Trading Info Stats)
   **неисключительные, безвозмездные, бессрочные права** на использование,
   изменение и **лицензирование вашего вклада на любых условиях, включая
   проприетарные/коммерческие** (Contributor License Agreement, CLA).
3. Ваш вклад также остаётся доступным сообществу под AGPL-3.0.

Если вы с этим не согласны — пожалуйста, не отправляйте PR (можно завести issue
с идеей/баг-репортом без передачи кода).

> В каждый PR можно добавлять строку-подтверждение:
> `Signed-off-by: Имя <email>` — означает согласие с условиями выше (DCO + CLA).

## Как внести изменения

1. Форкните репозиторий, создайте ветку (`feature/...` или `fix/...`).
2. Запуск: `py web_app.py` · Тесты: `py -m pytest -q`.
3. Не коммитьте секреты (`.env` в `.gitignore`). Ключи AI/FRED — только BYOK
   (в браузере), никогда в файлы.
4. Откройте PR с понятным описанием.

## Стиль

- Бэкенд — Python, фронтенд — vanilla JS (без сборщиков).
- Изменения в `templates/index.html` требуют перезапуска сервера; статика — нет.
